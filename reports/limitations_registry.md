# Limitations registry

| ID | Stage | Limitation | Consequence | Resolution/status |
|---|---|---|---|---|
| L-001 | Phase 0 | Host Windows installation lacks required genome-analysis executables. | Smoke tests cannot rely on the host PATH. | Build a repository-local Linux environment; do not reuse another project environment. |
| L-002 | Phase 0 | Assembly-only data can collapse the two 23S rRNA copies. | Heteroresistance and minor alleles may be missed. | Require at least one raw-read-supported principal cohort or downgrade clarithromycin claims. |
| L-003 | Phase 0 | Published studies use differing breakpoint standards/versions. | Binary phenotype labels may not be directly comparable. | Preserve original labels and MIC censoring; audit exact breakpoints before recomputation. |
| L-004 | Phase 0 | WSL environment linking on the E-drive case-insensitive filesystem produced duplicate-case Linux header/terminfo warnings, and Snakemake's Python `run` job split an interpreter path at the directory space. | Compiling new native software or using unquoted interpreter dispatch inside this prefix may be unreliable. | Use precompiled conda packages and shell-invoked repository-relative guard scripts; verify every required executable and workflow in the canonical directory. |
| L-005 | Phase 0 | Five HpGP phenotype IDs lack an exact current assembly-name link. | HpGP analyzable public set is 414, not 419. | Exclude unless an exact accession crosswalk is recovered. |
| L-006 | Phase 0 | Large US, Linqu, Swiss, and Eastern China sequence cohorts lack public isolate-level AST crosswalks. | Paper-level sample counts cannot become external validation observations. | Keep ineligible until a verifiable public crosswalk appears. |
| L-007 | Phase 0 | Zenodo 52 uses study-defined disk diffusion and overlapping levofloxacin endpoints. | Its labels are not a clean MIC-standard replication. | Restrict to secondary phenotype-method stress testing; never optimize thresholds on it. |
| L-008 | Phase 0 | Both currently linkable external cohorts are Chinese. | Strong global/geographic transportability claims are under-supported. | Add a non-Chinese phenotype-linked external cohort before such claims. |
| L-009 | Phase 0 | S27 primary mapping to 26695 was 59.11% and marker depth was only 4-14 in the smoke subset. | Low-depth loci can be miscalled if forced. | Enforce the frozen depth/quality/mixed-allele gates and report uncallable loci. |
| L-010 | Phase 1 | Public patient identifiers are unavailable for the phenotype-linked cohorts. | Patient-grouped splitting and a verified one-isolate-per-patient sensitivity cannot be estimated directly. | Use exact isolate/run/assembly deduplication and prespecified near-clone connected components as the resampling/grouping fallback; report patient-level checks as `NOT_ESTIMABLE`. |
| L-011 | Phase 2 | CheckM2 1.1.0 interpolates Prodigal/DIAMOND paths into unquoted shell commands. | Canonical project paths containing spaces cause upstream argument splitting. | Stage execution-only input/output paths and a database symlink under a no-space system temporary directory; copy all formal outputs back to E drive and retain the failed test log. |
